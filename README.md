# Analytics Portfolio

**Anastasia Mori · Product & Business Data Analyst | BI Analyst**

SQL, Python and BI projects focused on turning operational and financial data into reliable reporting and actionable business insights.

> **Portfolio scope:** this repository combines illustrative projects, synthetic datasets and sanitized examples. Any metrics shown in screenshots or generated datasets are demonstrational and should not be interpreted as production results.

## Skills demonstrated

- **SQL:** joins, CTEs, window functions, aggregations, conditional logic, data-quality checks
- **Python:** pandas-based transformations, validation, automation, exploratory analysis
- **BI:** Apache Superset dashboards, KPI definitions, drill-down reporting
- **Analytics:** business question framing, metric design, variance analysis, interpretation and recommendations
- **Systems & operations:** import monitoring, data flows, integration requirements, process automation

## How to review the portfolio

1. Start with the featured case most relevant to the role.
2. Read the business question and data assumptions before reviewing the code.
3. Check the SQL/Python implementation and the validation steps.
4. Review the screenshots and findings; illustrative values are clearly labeled as such.

## Data and reproducibility

Public examples use synthetic, anonymized or otherwise non-confidential data. Where source schemas or production data are not included, the code is intended to demonstrate the approach rather than run unchanged against a live database. Each project README state its prerequisites, assumptions and limitations.
